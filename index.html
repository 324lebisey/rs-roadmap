RICHSISTER(부자언니) 개인정보처리방침

시행일: 2026년 9월 12일

RICHSISTER(부자언니)(이하 "앱")는 개인 재무 관리를 돕는 웹 애플리케이션입니다. 본 방침은 앱이 어떤 정보를 다루고, 어떻게 보관·이용하는지 설명합니다.

1. 기본 동작 방식

앱은 별도의 서버 없이 사용자의 브라우저 안에서만 동작합니다. 입력하신 예산, 지출, 자산, 로드맵 등 모든 데이터는 사용자 기기의 브라우저 저장소(localStorage)에만 저장되며, 앱 운영자나 제3자의 서버로 전송되지 않습니다.

2. Google Drive 연동(선택 기능)

사용자가 직접 "드라이브에 저장" 또는 "드라이브에서 불러오기" 버튼을 눌렀을 때에만 Google Drive와 연동됩니다.

  • 권한 범위는 Google Drive API의 drive.file 스코프 하나뿐입니다. 앱이 직접 생성한 백업 파일에만 접근할 수 있으며, 사용자 드라이브의 다른 파일·폴더에는 접근할 수 없습니다.
  • 백업 파일에는 앱 내에서 입력한 재무 데이터(JSON)만 담기며, Google 계정의 다른 개인정보는 수집·저장하지 않습니다.
  • 업로드·다운로드는 버튼을 누른 시점에만 1회성으로 실행되며, 백그라운드 자동 동기화는 하지 않습니다.
  • 인증 토큰은 브라우저 세션에서만 임시로 쓰이며 별도 서버에 저장되지 않습니다.

3. 수집하지 않는 정보

광고 식별자, 위치 정보, 연락처, 추적 쿠키, 제3자 분석·광고 SDK를 수집하지 않습니다.

4. 제3자 제공

수집·저장되는 정보를 제3자에게 판매·대여·공유하지 않습니다. 법령상 요구되는 경우를 제외하고 외부에 제공하지 않습니다.

5. 보관 및 삭제

  • 로컬 데이터: 브라우저 사이트 데이터를 삭제하면 즉시 함께 삭제됩니다.
  • 드라이브 백업 파일: 사용자가 본인 Google Drive에서 직접 삭제할 수 있으며, 삭제 후 앱은 해당 파일에 접근할 방법이 없습니다.
  • Google 계정 연결 해제: Google 계정 > 보안 > 타사 앱 및 서비스 액세스 권한에서 언제든 가능합니다.

6. Google API 서비스 사용자 데이터 정책 고지
